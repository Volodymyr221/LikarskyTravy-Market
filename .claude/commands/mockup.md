# /mockup — ASCII-макет UI перед кодом

Аргумент: фіча або екран. Приклад: `/mockup product-card`, `/mockup checkout`.

## Що зробити
1. ASCII-макет (текстова схема) нового елемента / екрана — **у ширині телефона** (~32 символи), бо основний користувач мобільний.
2. **Усі стани:** порожній · завантаження · заповнений · помилка · активний/натиснутий (якщо доречно).
3. Розміри, якщо критично: ширина, висота, padding (внутрішні відступи), зона дотику (≥44px).
4. **Логіка:** що при тапі, свайпі, скролі; куди веде кожна кнопка; що бачить незалогінений.
5. Якщо бачиш кращий варіант, ніж просили, — покажи поруч як «Варіант Б» і поясни чому.

## Формат
```
┌──────────────────────────────┐
│ ←  Назва екрану          🔍  │
├──────────────────────────────┤
│ ┌──────┐ Назва товару        │
│ │ фото │ 120 ₴ · 50 г        │
│ └──────┘ [ − 1 + ] [Купити]  │
├──────────────────────────────┤
│ Порожньо: «Тут поки нічого»  │
└──────────────────────────────┘
```
