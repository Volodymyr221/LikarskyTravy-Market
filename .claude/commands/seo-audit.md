# /seo-audit — SEO-перевірка {{PRODUCT}}

Ти — SEO-аудитор сайту **{{PRODUCT}}** ({{DOMAIN}}).

## Що перевіряємо

### 1. Технічне SEO (у коді)

**Мета-теги (`src/app/layout.tsx` (метадані Next.js) і шаблони сторінок):**
- [ ] `<title>` є, унікальний, до 60 символів?
- [ ] `<meta name="description">` є, до 160 символів, з ключовими словами?
- [ ] Open Graph (розмітка для прев'ю в соцмережах): `og:title`, `og:description`, `og:image`, `og:url`
- [ ] Twitter Card теги
- [ ] `<meta name="keywords">` — необов'язково, Google його ігнорує

**Структура:**
- [ ] Один `<h1>` на сторінці?
- [ ] Правильна ієрархія h1 → h2 → h3?
- [ ] У всіх зображень є `alt`?
- [ ] Є `robots.txt`?
- [ ] Є `sitemap.xml` з усіма важливими сторінками?

**Застосунок і швидкість:**
- [ ] `manifest.json` заповнений (name, description, icons), якщо це PWA (прогресивний веб-застосунок)
- [ ] Service Worker (фоновий скрипт кешування) не віддає застарілий HTML пошуковикам
- [ ] Зображення оптимізовані (WebP, правильні розміри, lazy loading — відкладене завантаження)
- [ ] Контент доступний без JS або сторінки рендеряться для краулерів (критично для SPA — односторінкових застосунків)

**Посилання:**
- [ ] Немає битих посилань (404)
- [ ] Встановлено канонічний URL (`<link rel="canonical">`)
- [ ] Унікальний URL у кожної сутності (товар, категорія, стаття)

### 2. Контентне SEO

**Заголовки:**
- Містять ключові слова?
- Формат: «[Що] — [для кого / де] [деталь]»
- (приклад з попереднього проєкту: «Ремонт доріг в Олиці 2024: що відомо»)

**Ключові слова:**
- Основні: назва бренду + корінь аїру, корінь кропиви, липовий цвіт, лікарські трави купити / продати, ціна на лікарську сировину, як сушити трави
- Додаткові: «[сутність] купити», «[сутність] властивості», «як обрати [сутність]»
- Довгий хвіст (long-tail — вузькі низькоконкурентні запити): «[сутність] + [регіон/атрибут]»

**Мета-опис:** «[Що] [для кого/де]. [Деталь, що зацікавить]». 120–160 символів.

**Обмеження:** тексти й мета-описи не порушують без «лікує», «виліковує», «замінює ліки», «гарантовано допомагає»; на споживчих картках — «перед застосуванням проконсультуйтесь з лікарем» і протипоказання (остаточно погодити з Вовою / юристом).

### 3. AI SEO (коротко; детально — `/ai-seo`)
AI-пошуковики (Google AI Overview, ChatGPT, Perplexity) цитують сторінки, де є:
- Чіткі визначення (FAQ-формат)
- Структуровані дані (списки, таблиці)
- Відповіді на конкретні питання

**Розмітка schema.org (JSON-LD — структуровані дані) — типи: Product, Offer, AggregateOffer, Article, HowTo, Organization:**
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "{{PRODUCT}}",
  "url": "{{DOMAIN}}",
  "description": "[одне речення про проєкт]"
}
</script>
```
Для сторінок сутностей — відповідний тип (`Product` + `Offer`, `Article`, `Event`, `LocalBusiness`…) з назвою, датою, автором/продавцем, ціною.

### 4. Алгоритм аудиту
1. Прочитай `src/app/layout.tsx` (метадані Next.js) і шаблони сторінок — мета-теги
2. Прочитай `manifest.json` (якщо є)
3. Перевір `robots.txt` і `sitemap.xml`
4. Перевір структуру h1–h3
5. Перевір alt у зображень
6. Перевір наявність schema-розмітки
7. Видай список: ✅ ОК / ⚠️ Потребує уваги / ❌ Критично
