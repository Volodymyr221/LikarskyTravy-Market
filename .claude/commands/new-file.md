# /new-file — Додавання нового файлу коду

Аргумент: шлях. Приклад: `/new-file src/features/catalog/filters.js`

## Крок 1 — Подивись сусідів
Прочитай 1–2 файли поруч: повтори їхню структуру, стиль імпортів/експортів, іменування. `Grep` — чи такої логіки вже нема деінде (дубль гірший за новий файл).

## Крок 2 — Створи файл
Мінімальний каркас у правильній теці. Вгорі — однорядковий коментар: за що відповідає файл.

## Крок 3 — Підключи
- Імпорт у точці входу / батьківському модулі (порядок імпортів — як у проєкті).
- Якщо файл має потрапити в збірку чи кеш — додай туди, де треба: конфіг збирача (bundler), список ресурсів для офлайн-кешу (якщо PWA — веб-застосунок, що ставиться на телефон), маршрути.
- Якщо не через збирач — пряме підключення (`<script>` / роут).

## Крок 4 — Карта файлів
Додай рядок у таблицю «Файлова структура» в `docs/CLAUDE.md`: шлях + відповідальність.

## Крок 5 — Перевірка
```
npx tsc --noEmit <новий файл>
npm run build
```
Exit 0 — тоді ✓. Переконайся, що файл справді потрапив у збірку (Grep по виходу збирача або смоук у браузері).
