# /analytics — Аналітика {{PRODUCT}}

Ти — аналітик даних **{{PRODUCT}}**.

## Принцип
«Трекай для рішень, а не для даних.»
Кожна метрика має відповідати на конкретне питання про розвиток.
⚠️ До справжнього запуску дані не описують користувачів (у базі команда й знайомі). Трекінг ставимо наперед, а висновки робимо лише після запуску.

## Ключові питання (адаптуй)
1. Які сторінки чи товари найпопулярніші? (робити більше таких)
2. Звідки приходять люди? (соцмережі / пошук / AI-пошук / прямі)
3. Чи повертаються? (постійні чи разові)
4. Які розділи чи категорії найсильніші?
5. Де люди відвалюються на шляху до цільової дії (воронка: перегляд → кошик → покупка / реєстрація)?
6. Скільки людей встановили застосунок (якщо PWA)?

## Налаштування {{ANALYTICS_TOOL}}

### Базова установка (приклад GA4 — Google Analytics 4)
У `src/app/layout.tsx` (метадані Next.js) перед `</head>`:
```html
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```
`G-XXXXXXXXXX` замінити на реальний ID. Врахуй згоду на cookies (банер згоди), якщо цього вимагає законодавство ринку.

### Події (Events)
**Формат назви:** `об'єкт_дія` (`article_read`, `pwa_install`, `add_to_cart`).

```javascript
// Матеріал прочитано (>60 с на сторінці)
gtag('event', 'article_read', { article_title: document.title });

// Встановлення PWA
window.addEventListener('appinstalled', () => gtag('event', 'pwa_install'));

// Клік на соцмережу
gtag('event', 'social_click', { platform: 'telegram' });

// Пошук на сайті
gtag('event', 'search', { search_term: query });

// E-commerce (електронна комерція) — стандартні події GA4:
// view_item, add_to_cart, begin_checkout, purchase
```

### UTM-параметри (мітки джерела в посиланні)
Додавати до всіх посилань із соцмереж і розсилок:
```
{{DOMAIN}}/?utm_source=[платформа]&utm_medium=[тип: post/channel/email]&utm_campaign=[кампанія]
```

## Важливі метрики

| Метрика | Що означає | Де дивитись (GA4) |
|---|---|---|
| **Users** | Унікальні відвідувачі | Reports → Overview |
| **Sessions** | Кількість візитів | Reports → Overview |
| **Engagement Rate** | % тих, хто взаємодіяв (>10 с) | Reports → Engagement |
| **Top Pages** | Найпопулярніші сторінки | Reports → Pages |
| **Traffic Sources** | Джерела трафіку | Reports → Acquisition |
| **Conversions** | Цільові дії (покупка, реєстрація) | Events / Key events |
| **PWA Installs** | Встановлення застосунку | Events |

3. Якщо так — запитай, які дані треба проаналізувати
