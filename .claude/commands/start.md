# /start — синонім `/startuem` для цього репозиторію

Це локальний `/start` проєкту {{PROJECT_NAME}}. Логіка **та сама**, що `/startuem` — окремо не дублюємо, джерело правди одне.

## Що робити
1. Прочитай через Read `.claude/commands/startuem.md`.
2. Виконай його повністю як свої інструкції:
   - **Крок 0:** `git fetch` + `git pull origin main` → звірка `HEAD` з `origin/main` → журнал сесії `docs/_session-log/<дата>.md`.
   - **Крок 1:** обовʼязкове читання (першим — `docs/NOW.md`).
   - **Крок 2:** відповідь у стандартному форматі.
   - **Крок 3:** **чекати «Роби»** — без нього код не чіпати.

> Глобальний `/start` з інших проєктів тут не діє: у цьому репо `/start` == `/startuem`.
