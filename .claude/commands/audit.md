# /audit — Перевірка своєї роботи (легкий чекліст по diff)

> Не повний аудит застосунку (для нього — `/fullaudit`). Тут — лише файли, змінені в цій сесії: `git diff --stat origin/main...HEAD`.

Виконуй по порядку. Після кожного — коротко: що знайшов або «чисто».

1. **Перечитай усі змінені файли** — реально (Read), не з памʼяті.
2. **Синтаксис / типи / лінт:** `npx tsc --noEmit` на кожному. Exit 0 обовʼязковий.
3. **Збирання і тести:** `npm run build` + `npm test`.
4. **Розмітка:** баланс відкритих/закритих тегів у змінених шаблонах / HTML / JSX.
5. **Дублі:** функції / компоненти з однаковою назвою; та сама логіка скопійована в кількох місцях.
6. **Мертвий код:** залишки старого, невикористані змінні / імпорти / CSS-класи, закоментовані блоки.
7. **Підключення:** нові функції / обробники / маршрути (routes) справді зареєстровані й викликаються.
8. **Безпека швидко:** нема секретів / ключів у коді; користувацький ввід не йде в `innerHTML` / SQL без екранування; права перевіряє сервер, а не клієнт.
9. **Тихі відмови:** `catch`, що ковтає помилку без сигналу; мовчазний `return` на порожніх даних.
10. **Розмір:** файл >500 рядків — попередь Вову.

**Підсумок:** що знайдено · що виправлено · що потребує рішення. Без exit 0 у пп. 2–3 — не писати «все чисто».
