## Що робить цей скіл
Створює пости на основі:
- Готового матеріалу (URL або текст)
- Теми чи події
- Фото чи відео

## Алгоритм

### 1. Зібрати контекст (питай, якщо не вказано)
- Яка подія, товар чи новина?
- Яка платформа?
- Є фото чи відео?
- Мета: поінформувати / запустити обговорення / анонсувати / продати?

### 2. Структура поста за типом платформи

**Довгий формат (Facebook-подібні — основна дискусійна платформа):**
- Перший рядок — гачок (питання, факт, цитата, несподіваний початок)
- 2–4 абзаци по 1–3 речення
- Заклик до дії (CTA): питання до читачів, «поділіться», «напишіть у коментарях»
- 3–5 хештегів: бренд + ніша + тема

**Месенджер-канал (Telegram-подібні):**
- Коротко й по суті — 3–6 речень
- Емодзі помірно (1–3 на пост)
- Посилання на повний матеріал

**Візуальний (Instagram-подібні):**
- Сильний перший рядок до «читати далі»
- 15–20 тематичних хештегів
- Caption (підпис) окремо від хештегів

### 3. Принципи

**Гачки (шаблони):**
- «Чи знали ви, що…» (цікавий факт)
- «Вчора у нас…» (подія)
- «Про це зараз говорять…» (дискусія)
- «Важливо для [аудиторії]:» (термінове)

**Заборонено:**
- Офіційна мова
- Розмите «скоро буде…» без конкретики
- Клікбейт без змісту
- Обіцянки, що порушують без «лікує», «виліковує», «замінює ліки», «гарантовано допомагає»; на споживчих картках — «перед застосуванням проконсультуйтесь з лікарем» і протипоказання (остаточно погодити з Вовою / юристом)

**Repurposing (переупаковка):** один матеріал = 3 пости:
1. Факт чи подія → довгий формат (обговорення)
2. Цитата чи деталь → месенджер (коротко)
3. Візуальний момент → візуальна платформа (фото + підпис)

## Частота (орієнтир, підлаштуй під ресурс)
- Довгий формат: 1–2 рази на день
- Месенджер: 2–4 рази на день
- Візуальна платформа: 1 раз на день + сторіз (Stories)
